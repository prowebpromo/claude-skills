# gbp-optimization — weighted scorecard

Seven sections, 100 points. Score each item, sum per section, report the
band: **Maintain 85+ · Optimize 65–84 · Rebuild <65**. Items that cannot
be verified from available evidence are marked "unverified", excluded
from the denominator (rescale the section to its verifiable points), and
listed for client confirmation.

## 1. Identity & categories — 20 pts

| Item | Pts | Scoring |
|---|---|---|
| Business name matches real-world name, no keyword stuffing | 6 | 0 if stuffed (also raise as P1 policy risk) |
| Primary category is the money service, most specific available | 8 | 4 if close-but-generic (e.g. "Lawyer" vs "Personal injury attorney") |
| Secondary categories cover remaining services, no spam | 4 | −1 per irrelevant category |
| Verified listing, no duplicate listings live | 2 | 0 if duplicates found |

## 2. Completeness — 15 pts

| Item | Pts |
|---|---|
| Description present, ≤750 chars, services + city + differentiators, no URLs | 4 |
| Services section populated, each with a description | 4 |
| Attributes set (accessibility, payments, identity where applicable) | 2 |
| Hours incl. holiday hours current | 2 |
| Opening date, phone, website URL correct | 3 |

## 3. Media — 10 pts

| Item | Pts |
|---|---|
| ≥ 20 photos total; logo + cover set | 4 |
| Photo added within last 30 days | 3 |
| Interior/exterior/team categories covered (or video present) | 3 |

## 4. Reviews — 20 pts (benchmarked, not absolute)

| Item | Pts | Scoring |
|---|---|---|
| Review count ≥ median of the 3 pack winners for the top money query | 8 | 4 if ≥ half the median |
| Velocity: ≥ 2 new reviews/month over last 90 days | 4 | |
| Rating ≥ 4.5 (or ≥ pack median if pack median is lower) | 4 | |
| Owner responds to reviews (≥ 80% of last 20, incl. all negatives) | 4 | 2 if positives only |

## 5. Engagement — 10 pts

| Item | Pts |
|---|---|
| Post published within last 14 days; ≥ 2/month cadence | 4 |
| Q&A: seeded questions answered by owner; no unanswered public Qs | 3 |
| Messaging/chat enabled and response time healthy (dashboard-only: mark unverified without access) | 3 |

## 6. Website alignment — 15 pts

| Item | Pts |
|---|---|
| GBP links to the correct landing page (location page, not bare homepage, for multi-service/multi-location) | 4 |
| LocalBusiness (or subtype) JSON-LD present; NAP exactly matches canonical | 5 |
| Landing page title/H1 carries city + primary service | 3 |
| NAP in site footer matches canonical; map embed present | 3 |

## 7. Citations & NAP — 10 pts

| Item | Pts |
|---|---|
| Core directories (see citation_sources.md) present and NAP-consistent | 5 |
| Vertical directories for the client's industry present | 3 |
| No live duplicates on major directories | 2 |

## Local pack benchmark (reported alongside the score)

For each of 3–5 money queries: pack winners, their primary category,
review count, rating. Headline finding = the measurable gap between the
client and the WEAKEST pack entrant (that's the displacement target), not
the strongest.
